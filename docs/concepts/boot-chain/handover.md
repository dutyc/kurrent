# 交接给内核

**交接**把本次会话的连接事实留给内核：凭据表、发现信息，以及同一端口上的重连。固件建立的数据面连接只服务引导阶段；GRUB 与内核加载完成后，固件退出，操作系统要自己挂载根文件系统。此时内核并不知道刚才那条连接的任何信息，交接把这些事实补给它。

## NBCT 凭据表

固件在 `sanboot` 时安装一张 **NBCT** 凭据表（一张 ACPI 表，操作系统可以从固件留下的内存结构中读到它），记录本会话的：

- target 地址与端口；
- 子系统 NQN 与 Host NQN；
- DH-HMAC-CHAP 密钥。

TLS PSK 与数据面端口随 `sanboot` URI 交给后续阶段；NBFT 负责网络与子系统发现信息。

## initramfs 重连

initramfs 里的 `nbft-connect` 读取 **NBFT**（网络与子系统发现）与 **NBCT**（凭据与 Host NQN 中继），用同一端口以 `--tls` 重新连接，挂载根文件系统。

盘内不包含固定的机器身份：身份、凭据与连接信息都来自本次启动的投影。同一块盘换一台设备启动时，拿到的就是新设备的投影。
