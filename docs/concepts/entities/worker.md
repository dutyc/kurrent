# Worker

**Worker** 是计算身份。`worker_id` 同时充当主机名，是台账与凭据的索引键。它不是机器身份：换机时 Worker 保持不变，系统盘与凭据都挂在它名下，机器只是暂时承载这个身份的硬件，换绑设备时系统随之流动。

## 标识与记录

| 字段 | 含义 |
| --- | --- |
| `worker_id` | 计算身份，台账主键 |
| 绑定的设备 | 从设备台账投影，不在 Worker 侧单独存储 |
| `disks[]` | 已挂载的系统盘 |
| `default_disk` | 默认启动盘（`os_tag`） |
| `boot` | 菜单项与超时覆盖（可选） |
| `state` | `registered`（仅身份）或 `ready`（有系统盘） |

绑定设备只从设备台账投影，不在 Worker 侧另存一份，避免两处记录不一致。

## 就绪状态

`readiness` 是由台账派生的只读投影，回答「这个 Worker 现在能不能启动」：

| 值 | 条件 |
| --- | --- |
| `ready` | 已绑定设备且有系统盘 |
| `partial` | 只有绑定设备，或只有系统盘 |
| `idle` | 两者都没有 |
