> 周流六虚，上下无常，刚柔相易，唯变所适。——《周易·系辞下》

Kurrent（周流）是云原生无状态裸金属交付平台：K8S 让应用云原生，Kurrent 让计算云原生——计算不绑定硬件，如电流般在裸金属间周流，唯变所适。

## 特性

- **无状态计算**——计算节点零持久状态，插线即上线。
- **即插即用**——引导自动入池，WebUI 一键交付。
- **零学习成本**——声明式配置与 CLI 沿用 kubeadm / kubectl 的操作语义。
- **双数据面**——NVMe-oF 与 iSCSI，存储横向扩展。
